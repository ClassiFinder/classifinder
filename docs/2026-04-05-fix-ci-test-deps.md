# Fix CI Missing Test Dependencies Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the CI pipeline, which fails with `No module named pytest` because test dependencies are not included in `requirements.lock`.

**Architecture:** Generate a separate `requirements-dev.lock` (pinned dev deps compiled from `pyproject.toml [dev]` extras) and update the CI workflow to install it alongside `requirements.lock`. This keeps production deps separate from test deps, both fully pinned.

**Tech Stack:** uv (pip compile), GitHub Actions

---

## Root Cause

`requirements.lock` was compiled from `pyproject.toml` without `--extra dev`:

```bash
uv pip compile pyproject.toml -o requirements.lock
```

`pytest` lives under `[project.optional-dependencies] dev` in `pyproject.toml` and was never included. The CI installs only `requirements.lock`, so `python -m pytest` fails immediately.

### Task 1: Generate `requirements-dev.lock`

**Files:**
- Create: `classifinder/requirements-dev.lock`

- [ ] **Step 1: Compile dev dependencies into a lock file**

From the `classifinder/` directory:

```bash
cd classifinder
uv pip compile pyproject.toml --extra dev -o requirements-dev.lock
```

Expected output: a file like the following (versions may vary):

```
# This file was autogenerated by uv via the following command:
#    uv pip compile pyproject.toml --extra dev -o requirements-dev.lock
iniconfig==2.0.0
    # via pytest

    # via pytest
pluggy==1.5.0
    # via pytest

    # via classifinder (pyproject.toml)
```

Expected: one or more lines mentioning `pytest`.

### Task 2: Update CI to Install Dev Dependencies

**Files:**
- Modify: `classifinder/.github/workflows/deploy.yml`

Current `Install dependencies` step:

```yaml
- name: Install dependencies
  run: pip install -r requirements.lock
```

- [ ] **Step 1: Add the dev deps install step**

Replace the single install step with two sequential steps:

```yaml
- name: Install dependencies
  run: pip install -r requirements.lock

- name: Install dev dependencies
  run: pip install -r requirements-dev.lock
```

The full updated `test` job should look like:

```yaml
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@34e114876b0b11c390a56381ad16ebd13914f8d5 # v4

      - uses: actions/setup-python@a26af69be951a213d495a4c3e4e4022e16d87065 # v5
        with:
          python-version: "3.12"

      - name: Install dependencies
        run: pip install -r requirements.lock

      - name: Install dev dependencies
        run: pip install -r requirements-dev.lock

      - name: Run tests
        env:
          CLASSIFINDER_API_KEYS: "ss_test_abc123def456ghi789jkl012mno345pqr678stu901vwx"
          CLASSIFINDER_RATE_LIMIT_PER_MINUTE: "1000"
        run: python -m pytest tests/ -v
```

- [ ] **Step 2: Commit**

```bash

```
